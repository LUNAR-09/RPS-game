# 🎉 AI 가위바위보

웹캠으로 내 손 모양을 인식해 컴퓨터와 가위바위보를 겨루는 브라우저 게임입니다.
손 모양을 이모티콘으로 바꿔 보여주고, 두 이모티콘이 칼싸움하듯 부딪힌 뒤 이긴 쪽이 진 쪽을 날려 버리는 파티 분위기의 연출이 들어 있습니다.

👉 **데모**: `https://<내-아이디>.github.io/<저장소-이름>/`

## ✨ 주요 기능

- **손 모양 인식**: [Roboflow](https://roboflow.com)에서 학습시킨 가위·바위·보 분류 모델로 웹캠 화면을 인식합니다. 3장을 찍어 평균을 내므로 손이 잠깐 흔들려도 안정적입니다.
- **5초 간격 자동 진행**: '게임 시작'을 누르면 5초 카운트다운 후 손 모양을 인식하고 바로 승부를 냅니다.
- **이모티콘 대결 연출**: 내 손(✊ ✋ ✌️)과 컴퓨터의 랜덤 선택이 이모티콘으로 나타나 3번 부딪힌 뒤, 이긴 쪽이 진 쪽을 날려 보냅니다.
- **전투 시나리오**: 승부마다 5줄짜리 전투 이야기가 나옵니다. 같은 이야기가 연달아 나오지 않도록 순서를 섞어 보여줍니다.
- **효과음과 음성**: 칼이 부딪히는 소리, 관중 환호, 그리고 "○○가 이겼습니다!" 음성이 나옵니다. 효과음은 파일 없이 브라우저가 직접 합성합니다.
- **승리 연출**: 내가 이기면 폭죽이 터집니다. 승·무승부·패 전적도 계속 집계됩니다.

## 🕹️ 사용 방법

1. 페이지를 열고 카메라 권한을 허용합니다.
2. **게임 시작**을 누릅니다.
3. 카운트다운이 0이 되기 전에 카메라 가운데에 손 모양을 보여 주세요.
4. **게임 종료**를 누르면 최종 전적이 표시됩니다.

> 💡 손을 카메라 중앙에 크게 두고, 배경이 단순할수록 인식이 잘 됩니다. 소리가 나려면 브라우저 탭 소리가 켜져 있어야 합니다.

## 🛠️ 기술 스택

- HTML / CSS / JavaScript (프레임워크·빌드 과정 없이 `index.html` 한 파일)
- Roboflow Hosted Inference API (이미지 분류)
- Web APIs: `getUserMedia`(카메라), Web Animations, Web Audio, Web Speech(음성), Canvas(폭죽)

## 🚀 실행·배포

별도 설치 없이 `index.html` 하나로 동작합니다. 카메라는 보안상 `https` 또는 `localhost`에서만 켜집니다.

- **로컬 실행**: 폴더에서 `python -m http.server`를 실행한 뒤 `http://localhost:8000`으로 접속
- **GitHub Pages**: Settings → Pages → Branch를 `main` / `(root)`로 지정

## 🔑 API 키 안내

이 프로젝트는 서버 없이 브라우저에서 Roboflow API를 직접 호출하므로, 키가 소스 코드에 포함됩니다. 공개 저장소에 올릴 때는 다음을 권장합니다.

- 클라이언트용 게시용(Publishable) 키를 사용하거나, 키를 재발급해서 사용
- Roboflow에서 사용량 알림·한도 설정
- 키를 완전히 숨기려면 서버리스 함수(Cloudflare Workers, Vercel 등)를 중간에 두는 구조로 변경

본인의 모델을 쓰려면 `index.html` 상단의 `MODEL_ID`와 `API_KEY` 값을 바꾸면 됩니다.
